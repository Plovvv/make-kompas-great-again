# Как участвовать

## Новый мод

1. Скопируйте `mods/_template` в `mods/<id>` и поправьте `mkga-mod.json`.
2. Проверьте: `python -m mkga validate mods/<id>` и `python -m mkga check mods/<id>`. Запуск без КОМПАСа: `python -m mkga run-dev mods/<id> --fake-kompas`.
3. Добавьте тесты на ту часть логики, которая не требует КОМПАСа (разбор таблиц, формирование имён, расчёты).
4. Опишите в README мода, что он делает, с какими версиями КОМПАС проверен и откуда взяты данные.

## Правила для модов

- Основные правила проекта: [docs/PRINCIPLES.md](docs/PRINCIPLES.md). Прочитайте их до начала работы.
- Файлы пользователя мод пишет и удаляет ТОЛЬКО через `ctx.session(...)` (снимок, откат, предпросмотр,
  корзина), документы КОМПАСа сохраняет через `k.save_as(session, doc, path)`. Прямые `open(..., "w")`,
  `os.remove`, `shutil.*`, `doc.SaveAs` и т.п. ловит `python -m mkga check mods/<id>` (он же в CI).
- Константы КОМПАСа берутся из `mkga.core.constants` (`from mkga.core import constants as C`). Нужной нет в списке: добавьте её или шаблон в группы `tools/gen_constants.py` и запустите генератор на машине с КОМПАСом, файл вручную не правится.
- Окна модов строятся на `mkga.ui.window.ModWindow` по правилам [docs/UI_STYLE.md](docs/UI_STYLE.md); образец: `python -m mkga ui-demo`. Размеры в пикселях только через `theme.px()`.
- Сообщения пользователю идут через `ctx.log`, а не в модальные окна КОМПАСа.
- В `kompas_versions` указываются только версии, на которых мод реально запускали.
- Данные из стандартов и каталогов производителей берутся из первоисточников, источник указывается. Базы, модели и библиотеки АСКОН не копируются.
- Мод не скачивает и не выполняет код из сети во время работы.
- Мод не должен молча удалять и перезаписывать файлы.

## Код

- Python 3.10+, без обязательных зависимостей в ядре хаба (стандартная библиотека).
- Живая проверка на вашей версии КОМПАСа (по желанию, очень полезна): `$env:MKGA_LIVE_KOMPAS = "1"; python -m unittest tests.test_live_kompas -v`. Тест создаёт свой пустой документ и пишет только во временную папку; пришлите версию КОМПАСа, редакцию и результат.
- Перед pull request: `python -m unittest discover -s tests -t .` и `python tools/validate_registry.py`.

## Добавление мода в реестр

Pull request, который добавляет или обновляет запись в `registry/registry.json`: `id`, `repo`, `tag`, `sha256` архива релиза. Хеш: `python -c "from mkga.installer import sha256_file; print(sha256_file('архив.zip'))"`.
