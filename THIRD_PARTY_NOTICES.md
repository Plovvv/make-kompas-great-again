# Сторонние компоненты

Собранная версия MKGA (`MKGA.exe`, `mkga-cli.exe`) включает сторонние компоненты. Исходный код самого MKGA распространяется
по лицензии MIT (см. `LICENSE`). Список составлен по документации компонентов; перед выпуском проверьте актуальные условия
на страницах проектов.

| Компонент | Зачем | Лицензия (по документации проекта) |
|---|---|---|
| Python (интерпретатор и стандартная библиотека, включая tkinter) | исполнение хаба и модов | Python Software Foundation License |
| Tcl/Tk (вместе с Python) | окна хаба и модов | BSD-подобная лицензия Tcl/Tk |
| PyInstaller (загрузчик в составе exe) | упаковка в exe | GPL-2.0 с исключением для собранных приложений (исключение позволяет распространять exe под своей лицензией) |
| pywin32 | связь с КОМПАС-3D через COM | PSF-подобная лицензия (Python Software Foundation License) |
| tzdata | база часовых поясов | Apache-2.0 |

MKGA не содержит и не распространяет программное обеспечение, модели и базы данных АСКОН. «КОМПАС» и «КОМПАС-3D»:
товарные знаки АСКОН; проект неофициальный и с АСКОН не связан.

Размеры стандартных изделий в моде «Каталог комплектующих» взяты из открытых каталогов; источник записан в каждом файле
таблицы (`mods/components/data/standards/*.json`, поле `source`). Они не сверены с оригиналами стандартов.
