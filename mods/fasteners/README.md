# Метизы и фитинги

Каталог стандартных крепёжных деталей для КОМПАС-3D. Выбираете стандарт, типоразмер, длину, папку, нажимаете
«Создать деталь»: мод строит отдельную 3D-деталь с **вашим** именем (например «Винт DIN 912 - M8 x 25») и нужным разделом
спецификации. Деталь можно сразу открыть в новой вкладке КОМПАС.

Зачем, если в КОМПАС есть встроенные «Стандартные изделия»:

1. Здесь стандарты и имена, которые нужны вам: `DIN 912`, а не `Hexagon socket head cap screw ISO 4762`.
2. Имя и раздел спецификации ставятся сразу, без «скачать модель, открыть, переименовать, вставить».
3. Детали лёгкие: резьба только условным изображением, нет тысяч полигонов от конвертации.
4. Свои детали добавляются таблицей (см. [docs/ADDING_PARTS.md](docs/ADDING_PARTS.md)), в том числе с помощью ИИ.

## Что внутри

| Стандарт | Что это | Типоразмеры |
|---|---|---|
| DIN 912 (ISO 4762) | Винт с цилиндрической головкой и шестигранным углублением | M1,6 … M36, длины 2,5 … 200 |
| DIN 7991 (ISO 10642) | Винт с потайной головкой и шестигранным углублением | M3 … M20, длины 8 … 100 |
| ISO 7380 | Винт с полукруглой головкой и шестигранным углублением | M3 … M16, длины 6 … 60 |
| DIN 125 A (ISO 7089) | Шайба плоская | M1,6 … M36 |
| DIN 127 B | Шайба пружинная | M3 … M36 |
| DIN 934 (ISO 4032) | Гайка шестигранная | M1,6 … M36 |

Классы прочности (8.8, 12.9, A2-70 …) выбираются списком и добавляются в конец имени; по умолчанию «не указывать».

## Как называется деталь и куда она попадает в спецификацию

| Что | Значение |
|---|---|
| Имя файла | `Винт DIN 912 - M8 x 25.m3d` |
| «Наименование» | `Винт с цилиндрической головкой и шестигранным углублением под ключ DIN 912 - M8 x 25` |
| «Обозначение» | не заполняется |
| Раздел спецификации | стандартные изделия (винты, гайки, шайбы): тип объекта «Стандартное изделие»; покупные без стандарта (раздел «Прочие изделия»): объект спецификации в разделе 40 |

## Как запускать

```powershell
python -m mkga run-dev mods/fasteners      # нужен запущенный КОМПАС, Windows, pywin32
python -m mkga run-dev mods/fasteners --fake-kompas   # без КОМПАС: окно открывается, но деталь не строится
```

Из собранного хаба: «Из файла» → архив мода (`python -m mkga pack mods/fasteners --repo владелец/репозиторий`).

## Что проверено (КОМПАС-3D v24, полная версия)

Тесты `tests/test_live_fasteners.py` строят детали на живом КОМПАС и **сверяют объём с расчётом по формуле**:

- DIN 912, DIN 7991, ISO 7380, DIN 125 A, DIN 127 B: объём совпадает с точностью 1e-6 (ISO 7380: 2e-3, см. ниже);
- DIN 934: плоские грани совпадают с расчётом до 1e-4, объём до 3 %;
- условное изображение резьбы создаётся, объём детали не меняется; неполная резьба идёт от самого конца винта;
- в сохранённом файле после повторного открытия читаются «Наименование» и «Тип объекта»;
- из окна: деталь создаётся, открывается в новой вкладке, замена существующего файла со снимком для отката.

### Почему у гаек и полукруглых головок допуск по объёму шире

Встроенный расчёт массы КОМПАС неточен, когда плоскость или сфера с углублением пересекается с конусом (гиперболические
кромки): расхождение с точной формулой до 1,3 %, хотя геометрия верна. Поэтому для этих форм дополнительно сверяется
**суммарная площадь плоских граней** (точный независимый признак, допуск 1e-4), а объём остаётся грубой проверкой.

## Не проверено

- Как деталь с разделом «Прочие изделия» отображается в спецификации **сборки** (в самой детали объект спецификации
  создаётся и сохраняется, проверено).
- Другие версии КОМПАС (v25 и новее) и учебная редакция.
- Размеры не сверены с оригиналами стандартов: взяты из открытых каталогов (источник записан в каждом файле, в окне
  кнопка «Источник и допущения…»). Поле `verified` ставится человеком после сверки.

## Упрощения модели

- Резьба: только «Условное изображение резьбы», витков нет.
- Шестигранное углубление плоское на глубину t (min), без конуса на дне.
- Фаски: верх головки DIN 912 0,06·dk, конец стержня на глубину резьбы; у гаек 30° от dw с обоих торцов.
- Скругления под головкой не моделируются. ISO 7380: головка это шаровой сегмент высотой k на основании dk.
- DIN 127 B: плоское кольцо без разреза и скручивания.

Подробности по каждому стандарту в поле `notes` файла `data/standards/*.json`.

## Устройство

```
main.py                    точка входа (run(ctx))
mkga_fasteners/
  shapes.py                формы: построение детали и точный расчёт объёма
  catalog.py               загрузка и проверка таблиц, имена деталей
  builder.py               создание детали: построение, свойства, сверка, сохранение через сессию отката, открытие
  drawing.py               2D-чертёж (примитивы, SVG, Tk)
  ui.py, custom.py         окно и «Свои детали»
data/categories.json       папки дерева
data/standards/*.json      таблицы стандартов (по одному файлу)
docs/ADDING_PARTS.md       как добавить свою деталь
```
