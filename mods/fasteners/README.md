# Метизы и фитинги (план)

Статус: заготовка. Кода построения деталей пока нет.

## Зачем, если в КОМПАСе уже есть «Стандартные изделия: Крепеж»

Встроенный каталог большой (сотни тысяч моделей), но мод должен быть удобнее в трёх местах:

1. **Быстрый поиск одной строкой**: `DIN 7991 M2.5x8`, `ГОСТ 11738 М4х10`, `T-гайка 2020 M4`.
2. **То, чего нет в каталоге**: вплавляемые вставки, Т-гайки под алюминиевый профиль, фитинги и штуцеры (G, NPT, ёлочки), эжекторы и другие покупные изделия.
3. **Оформление без ручной работы**: наименование, обозначение, материал и раздел спецификации ставятся автоматически по правилам пользователя («Стандартные изделия» для ГОСТ, «Прочие» для DIN и покупных).

Базу «Стандартные изделия» АСКОН не копируем и не перепаковываем: мод может её только использовать через установленный у пользователя КОМПАС.

## Данные

Каждое семейство описывается файлом `data/families/<id>.json`: стандарт, тип, таблица типоразмеров (размеры, масса), правила именования. Таблицы размеров берём из первоисточников (тексты стандартов, каталоги производителей), источник указываем в самом файле. Недостоверные значения не добавляем.

## Этапы

1. Каталог и поиск без построения деталей (проверка интерфейса).
2. Построение детали через API по таблице: DIN 912, 7991, 933, гайки, шайбы.
3. Вставка в открытую сборку, повторное использование уже построенных деталей из библиотеки пользователя.
4. Вплавляемые вставки, Т-гайки, фитинги.
5. Добавление чужих STEP-моделей в каталог одной кнопкой.
