# Каталог комплектующих

Каталог стандартных и покупных комплектующих для КОМПАС-3D (сейчас крепёж DIN/ISO, дальше вставки, фитинги и другое). Выбираете стандарт, типоразмер, длину, папку, нажимаете
«Создать деталь»: мод строит отдельную 3D-деталь с **вашим** именем (например «Винт DIN 912 - M8 x 25») и нужным разделом
спецификации. Деталь можно сразу открыть в новой вкладке КОМПАС.

Зачем, если в КОМПАС есть встроенные «Стандартные изделия»:

1. Здесь стандарты и имена, которые нужны вам: `DIN 912`, а не `Hexagon socket head cap screw ISO 4762`.
2. Имя и раздел спецификации ставятся сразу, без «скачать модель, открыть, переименовать, вставить».
3. Детали лёгкие: резьба только условным изображением, нет тысяч полигонов от конвертации.
4. Свои детали добавляются таблицей (см. [docs/ADDING_PARTS.md](docs/ADDING_PARTS.md)), в том числе с помощью ИИ.

| Изделие | Имя файла (пример) | Типоразмеры |
|---|---|---|
| Вставка резьбовая латунная для вплавления в пластик | `Вставка (вплавляемая) - M3 x 5,7` | M2 … M8, по 2-4 длины |
| Стойка шестигранная штифт-гайка и гайка-гайка | `Стойка (штифт-гайка) - M3 x 20` | M2,5 … M6, длины 5 … 40 |

Классы прочности (8.8, 12.9, A2-70 …) выбираются списком и добавляются в конец имени; по умолчанию «не указывать».

## Как называется деталь и куда она попадает в спецификацию

| Что | Значение |
|---|---|
| Имя файла | `Винт DIN 912 - M8 x 25.m3d` |
| «Наименование» | `Винт с цилиндрической головкой и шестигранным углублением под ключ DIN 912 - M8 x 25` |
| «Обозначение» | не заполняется |
| Раздел спецификации | винты, гайки, шайбы: **«Стандартные изделия»** (раздел 25); покупные без стандарта (вставки, фитинги): **«Прочие изделия»** (раздел 30). Ставится автоматически: в деталь записывается объект спецификации с этим разделом (он и определяет раздел в спецификации сборки), а также свойство «Раздел спецификации» и тип объекта «Стандартное изделие» |

## Как запускать

```powershell
python -m mkga run-dev mods/components      # нужен запущенный КОМПАС, Windows, pywin32
python -m mkga run-dev mods/components --fake-kompas   # без КОМПАС: окно открывается, но деталь не строится
```

Из собранного хаба: «Из файла» → архив мода (`python -m mkga pack mods/components --repo владелец/репозиторий`).

## Свои имена

Если нужно другое название (например «Болт ISO 4762» вместо «Винт DIN 912»), есть два способа:

- **Для одной детали:** перед созданием поправьте поля «Файл» и «Наименование» прямо в окне. Правка действует, пока вы не
  смените типоразмер, длину или класс; кнопка «Имена по стандарту» возвращает расчётные имена.
- **Для стандарта насовсем:** кнопка «Свои имена…» (вид изделия, обозначение, полное название). Имена хранятся только у вас
  (`names.json` в папке данных мода, запись с откатом), «Вернуть по стандарту» убирает правку. Таблицы размеров при этом не
  меняются.

## Что проверено (КОМПАС-3D v24, полная версия)

Тесты `tests/test_live_components.py` строят детали на живом КОМПАС и **сверяют объём с расчётом по формуле**:

- DIN 912, DIN 7991, DIN 125 A: объём совпадает с точностью 1e-6; DIN 127 B (с разрывом): объём и плоские грани до 1e-6;
- ISO 7380-1 и ISO 7380-2: плоские грани до 1e-4, объём до 2e-3 (см. ниже);
- DIN 934, DIN 439, DIN 985, DIN 933, DIN 931 (и их аналоги DIN 960/961, 986, 1587): плоские грани совпадают с расчётом до 1e-4, объём до 3 %; остальные новые формы (шлиц и крест, квадратная гайка, кольца, вставки, стойки, Т-гайка, фитинги) до 1e-6;
- условное изображение резьбы создаётся, объём детали не меняется; неполная резьба идёт от самого конца винта;
- в сохранённом файле после повторного открытия читаются «Наименование», «Тип объекта» и раздел спецификации;
- **в спецификации сборки** деталь попадает в «Стандартные изделия» (25) или «Прочие изделия» (30): проверено на скрытой сборке со спецификацией;
- из окна: деталь создаётся, открывается в новой вкладке, замена существующего файла со снимком для отката.

### Почему у гаек и полукруглых головок допуск по объёму шире

Встроенный расчёт массы КОМПАС неточен, когда плоскость или сфера с углублением пересекается с конусом (гиперболические
кромки): расхождение с точной формулой до 1,3 %, хотя геометрия верна. Поэтому для этих форм дополнительно сверяется
**суммарная площадь плоских граней** (точный независимый признак, допуск 1e-4), а объём остаётся грубой проверкой.

## Упрощения новых форм

- Шлиц и крест: прямоугольные вырезы на плоском верху головки, не доходящие до края. У DIN 7985 (полукруглая головка) верх
  показан плоским. Размеры креста условные.
- Стопорные кольца DIN 471/472: плоское кольцо с разрывом (проушин нет), ширина разрыва условная.
- Вставка: гладкий цилиндр с резьбовым отверстием (без рифления). Стойки: шестигранник без фасок. Т-гайка: брусок.
- Фитинги push-in: шестигранник, резьбовой цилиндр, цилиндрический корпус и гнездо под трубку; корпус и глубина гнезда
  рассчитаны условно, резьба G показана вместо конической R из источника.
- Колпачковые гайки DIN 986/1587: колпачок цилиндр (без купола); высота шестигранника у DIN 1587 принята h - dk/2.

## Не проверено

- Как строка «Раздел спецификации» выглядит в окне свойств детали в самом КОМПАС: значение записывается в хранилище свойств
  (проверено чтением), отображение в интерфейсе нужно проверить глазами.
- Другие версии КОМПАС (v25 и новее) и учебная редакция.
- Размеры не сверены с оригиналами стандартов: взяты из открытых каталогов (источник записан в каждом файле, в окне
  кнопка «Источник и допущения…»). Поле `verified` ставится человеком после сверки.

## Упрощения модели

- Резьба: только «Условное изображение резьбы», витков нет.
- Шестигранное углубление плоское на глубину t (min), без конуса на дне.
- Фаски: верх головки DIN 912 0,06·dk, конец стержня на глубину резьбы; у гаек 30° от dw с обоих торцов.
- Скругления под головкой не моделируются. ISO 7380-1: головка это шаровой сегмент высотой k на основании dk; ISO 7380-2: купол высотой k - c на фланце толщиной c.
- DIN 916: чашечное углубление на торце не моделируется (конец плоский диаметром dz); установочные винты имеют резьбу на всю длину.
- DIN 933 / 931: низ головки плоский (без подшайбного пояска), dw ≈ 0,9·s (в источнике нет). DIN 985: шестигранник высотой m и буртик диаметром dw до полной высоты h, нейлоновое кольцо не моделируется.
- DIN 127 B: кольцо с разрывом шириной s (ширина разрыва условная, в таблицах стандарта её нет), без скручивания.

Подробности по каждому стандарту в поле `notes` файла `data/standards/*.json`.

## Устройство

```
main.py                    точка входа (run(ctx))
mkga_components/
  shapes.py                формы: построение детали и точный расчёт объёма
  catalog.py               загрузка и проверка таблиц, имена деталей
  builder.py               создание детали: построение, свойства, сверка, сохранение через сессию отката, открытие
  drawing.py               2D-чертёж (примитивы, SVG, Tk)
  ui.py, custom.py         окно и «Свои детали»
data/categories.json       папки дерева
data/standards/*.json      таблицы стандартов (по одному файлу)
docs/ADDING_PARTS.md       как добавить свою деталь
```
