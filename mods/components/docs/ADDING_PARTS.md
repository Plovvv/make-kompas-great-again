# Как добавить свою деталь или стандарт

Каждая деталь в каталоге это **таблица размеров в одном файле JSON**. Свой файл остаётся только у вас, в дереве каталога он
помечен звёздочкой. Код писать не нужно, если подходит одна из готовых форм (см. ниже).

## Быстрый путь (кнопки в окне)

1. Откройте мод, нажмите **«Свои детали…»**.
2. **«Заготовка из выбранного…»**: создаст копию выбранного стандарта с новым id (`my-…`) в папке своих деталей и откроет
   её в редакторе. Или **«Инструкция для ИИ»**: копирует в буфер обмена готовое задание, вставьте его в чат с ИИ вместе со
   ссылкой на таблицу размеров (или фото страницы); ИИ вернёт готовый JSON.
3. Сохраните файл в папку своих деталей (**«Открыть папку»**; обычно `%APPDATA%\MKGA\data\fasteners\standards`).
4. Нажмите **«Обновить каталог»**. Ошибки в файле покажет журнал, остальной каталог продолжает работать.

Все действия записи файлов идут через историю изменений хаба: заготовку можно отменить.

## Формат файла

```json
{
  "id": "my-din-912-short",
  "category": "screws",
  "number": "DIN 912 (мой)",
  "aliases": ["ISO 4762"],
  "kind_name": "Винт",
  "full_name": "Винт с цилиндрической головкой и шестигранным углублением под ключ",
  "section": "standard",
  "shape": "cap_screw",
  "lengths": [10, 12, 16, 20, 25, 30],
  "classes": ["8.8", "A2-70"],
  "source": "каталог производителя, страница 12 (ссылка)",
  "verified": false,
  "notes": "что упрощено",
  "sizes": {
    "M8": {"d": 8, "P": 1.25, "dk": 13, "k": 8, "s": 6, "t": 4, "b": 28, "lmin": 12, "lmax": 120}
  }
}
```

| Поле | Что значит |
|---|---|
| `id` | латиница в нижнем регистре, цифры, дефис, до 40 знаков; уникален. Совпадающий с встроенным id заменяет встроенный стандарт |
| `category` | папка в дереве: `screws`, `nuts`, `washers`, `pins`, `inserts`, `pneumatics`, `profiles`, `other` |
| `number` | обозначение: попадает в имена («DIN 912») |
| `aliases` | аналоги, только справка в окне |
| `kind_name` | короткое имя для **имени файла** («Винт») |
| `full_name` | полное имя для поля **«Наименование»** детали |
| `section` | `standard`: раздел «Стандартные изделия»; `other`: «Прочие изделия» (покупное без стандарта) |
| `shape` | форма детали (таблица ниже) |
| `lengths` | ряд длин по возрастанию (для форм с длиной) |
| `classes` | необязательно; выбранный класс добавляется в конец имени |
| `source` | **обязательно**: откуда взяты размеры |
| `verified` | `true`, только если вы сверили таблицу с оригиналом стандарта |
| `sizes` | строки таблицы: ключ типоразмер («M8»), значения размеры в мм; `lmin`/`lmax` ограничивают ряд длин |

Итоговые имена: файл `<kind_name> <number> - <типоразмер> x <длина> - <класс>`, «Наименование»
`<full_name> <number> - <типоразмер> x <длина> - <класс>`. «Обозначение» не заполняется.

## Готовые формы

| `shape` | Что строит | Размеры строки |
|---|---|---|
| `cap_screw` | винт с цилиндрической головкой и шестигранным углублением (DIN 912) | `d, P, dk, k, s, t`, необязательно `b` (длина резьбы от конца) |
| `csk_screw` | винт с потайной головкой 90° (DIN 7991), длина от верха головки | `d, P, dk, k, s, t`, необязательно `b` |
| `button_screw` | винт с полукруглой головкой (ISO 7380) | `d, P, dk, k, s, t`, необязательно `b` |
| `washer_flat` | плоская шайба | `d1, d2, h` |
| `washer_spring` | пружинная шайба (плоское кольцо) | `d1, b, s` |
| `nut_hex` | шестигранная гайка с фасками 30° | `d, P, s, m, dw` |
| `hex_bolt` | болт с шестигранной головкой (DIN 933 резьба на всю длину, DIN 931 неполная), фаска 30° сверху | `d, P, s, k, dw`, необязательно `b`, `b2`, `b3` (длина резьбы при l ≤ 125, ≤ 200, больше) |
| `set_screw` | установочный винт с шестигранным углублением, резьба на всю длину, конец с фаской 45° до диаметра dp (DIN 913/914/916) | `d, P, dp, s, t` |
| `pin_dowel` | цилиндрический штифт с фасками на торцах (ISO 2338) | `d, c` |
| `nut_nyloc` | самоконтрящаяся гайка с нейлоновым кольцом (DIN 985): шестигранник и буртик | `d, P, s, m, h, dw` |
| `flange_button_screw` | винт с полукруглой головкой и фланцем (ISO 7380-2) | `d, P, dk, dc, k, c, s, t`, необязательно `b` |

Значения `d, d1, d2, dk, k, s, t, m, dw, b, h` это размеры из стандарта в мм (обозначения как в самом стандарте; расшифровка
под чертежом в окне). `P` шаг резьбы.

Примеры: для **DIN 125 B**, **DIN 9021** и других плоских шайб достаточно новой таблицы с формой `washer_flat`; для
**DIN 6798** (зубчатая шайба), **DIN 933** (болт с шестигранной головкой) и **DIN 985** (самоконтрящаяся гайка) нужна новая
форма (см. следующий раздел).

## Если нужной формы нет

Форма это небольшая функция Python в `mkga_components/shapes.py`: профиль вращения, при необходимости выдавливание
шестигранника, **точный расчёт объёма** и резьба. Правило проекта: новая форма добавляется только вместе с живой проверкой
на КОМПАС (`tests/test_live_components.py`), где объём сверяется с расчётом. Задача для ИИ формулируется так: «добавь форму по образцу
`cap_screw`, объём считай формулой, добавь живой тест». Подробности: `docs/MODEL3D.md` проекта.

## Правила для данных

- Размеры из надёжных источников и в мм: сам стандарт, каталог производителя. Источник записывается в `source`.
- Не выдумывайте и не «подгоняйте» значения. Нет числа, не добавляйте типоразмер.
- `verified` меняет только человек после сверки с оригиналом.
- Проверка перед сохранением выполняется при загрузке: каждый типоразмер пробно строится по формуле, несогласованные
  размеры (например шестигранник не помещается в головку) отклоняются с понятным сообщением.

## Версия мода

Новый стандарт или правка таблицы в репозитории: только третья цифра версии в `mkga-mod.json` (0.4.0 → 0.4.1), и то не с каждым винтом, а когда выпускается релиз.

## Как поделиться

Чтобы деталь попала в общий каталог всех пользователей:

1. Откройте в репозитории проекта на GitHub задачу **«Предложить мод или деталь»** и приложите свой файл `.json`
   (и укажите источник размеров).
2. Или сделайте pull request: положите файл в `mods/components/data/standards/`. Автоматические тесты проверят формат и то, что
   каждый типоразмер строится, а перед слиянием человек сверит размеры с источником.
