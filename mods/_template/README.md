# Шаблон мода

1. Скопируйте папку `mods/_template` в `mods/<ваш-id>` или в отдельный репозиторий.
2. Поправьте `mkga-mod.json` (описание полей в `docs/ARCHITECTURE.md`).
3. Логику пишите в `main.py` в функции `run(ctx)`.
4. Проверьте манифест: `python -m mkga validate mods/<ваш-id>`.
5. Соберите zip так, чтобы `mkga-mod.json` лежал в корне архива или в единственной папке внутри него.
6. Установите для проверки: `python -m mkga install-zip путь/к/архиву.zip`, запустите: `python -m mkga run <ваш-id>`.

Правила для модов:
- Не меняйте исходные файлы пользователя. Работайте с копией или с новым файлом.
- Не скачивайте и не запускайте код из сети во время работы.
- Если мод использует чужие данные (таблицы размеров, модели), укажите источник и лицензию в README мода.
