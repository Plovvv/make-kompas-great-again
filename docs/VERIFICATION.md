# Проверка на вашем КОМПАС

Проект проверялся на КОМПАС-3D v24 (полная версия). Чтобы его можно было честно рекомендовать на других версиях и
редакциях, нужны проверки на них. Это занимает несколько минут и безопасно для ваших файлов.

## Что делают проверки

- Подключаются к уже **запущенному** КОМПАС (второй экземпляр не создаётся).
- Читают версию и редакцию, сверяют константы с установленной библиотекой типов.
- Создают **свой новый пустой документ** (скрытый), строят в нём тела и сверяют массу с расчётом по формуле,
  сохраняют документ **только во временную папку** (проверяя откат) и закрывают его без сохранения.
- Ваши документы не открываются, не меняются и не закрываются. После проверок число открытых документов и активный
  документ те же, что были. Тесты сами это проверяют.

Откройте КОМПАС (документы можно не закрывать) и в терминале в папке проекта:

```powershell
$env:MKGA_LIVE_KOMPAS = "1"
python -m unittest tests.test_live_kompas tests.test_live_model3d -v
```

Если запускаете собранный `mkga-cli.exe`, живые тесты ему не нужны: проверка «подключение, версия, редакция» есть в самом
хабе (кнопка «Проверить»).

## Как сообщить результат

Откройте issue «Отчёт о проверке на КОМПАС» (форма в репозитории) и вставьте вывод. Нужны: версия и редакция КОМПАС
(плашка статуса в хабе), версия MKGA и Windows, что прошло и что нет. Не прошедшие проверки тоже ценны: они показывают,
что отличается в вашей версии (имена методов, значения констант, поведение).

## Что делать с результатом

Мейнтейнер вносит результат в [COMPATIBILITY.md](COMPATIBILITY.md). Версия попадает в список «проверено» только после
прохождения живых тестов. Моды заявляют в `kompas_versions` только проверенные версии; для остальных хаб предупреждает.
