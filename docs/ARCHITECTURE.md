# Архитектура

```
GitHub: registry/registry.json  ──►  хаб (mkga)  ──►  %APPDATA%\MKGA\mods\<id>\  ──►  run(ctx)  ──►  КОМПАС (COM)
        релизы модов (zip) ─────────────┘
```

## Модуль мода

Мод — папка (или zip) с файлом `mkga-mod.json` и Python-файлом из поля `entry`. В нём функция `run(ctx)`.

Поля манифеста:

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | латиница в нижнем регистре, цифры, дефис; 2–40 символов |
| `name`, `description`, `author`, `license` | да | текст |
| `version` | да | `MAJOR.MINOR.PATCH` |
| `kind` | да | `app` (своё окно), `macro` (один запуск), `library` (код для других модов) |
| `entry` | да | относительный путь к `.py` внутри мода, без `..` |
| `kompas_versions` | нет | проверенные версии КОМПАС, числа от 17 |
| `tags`, `homepage` | нет | для поиска и ссылки |
| `requires` | нет | pip-пакеты (пока только информационно) |

## Реестр

`registry/registry.json`: `{"schema": 1, "mods": [...]}`. Запись: `id`, `name`, `description`, `repo` (`owner/name`), `tag`, `sha256`, `tags`. Архив берётся из релиза: `https://github.com/<repo>/releases/download/<tag>/<id>-<tag>.zip`.

Запись закреплена за тегом и хешем. Это сделано как в реестре Obsidian: код не меняется незаметно после проверки, а обновление версии проходит через pull request. Запись проверяется автоматически (`.github/workflows/registry.yml`, `python -m mkga verify-registry`): скачивается архив релиза и сверяются хеш, манифест, версия, безопасность zip и страж правил (код мода не выполняется). Архив собирает `python -m mkga pack`: он воспроизводим, то есть тот же код даёт тот же хеш. Подробности для авторов: [WRITING_MODS.md](WRITING_MODS.md).

## Безопасность установки

- скачивание только по https, хеш архива сверяется с реестром до распаковки;
- распаковка защищена от `..`, абсолютных путей, символьных ссылок и zip-бомб (пределы числа файлов и размера);
- `id` в манифесте обязан совпасть с `id` в реестре;
- старая версия заменяется целиком, при ошибке остаётся прежняя;
- каждый мод запускается ОТДЕЛЬНЫМ процессом: сбой мода не роняет хаб и другие моды. Но это не песочница: у мода те же права на файлы и систему, что у пользователя, поэтому ставить стоит только проверенные моды из реестра.

## Ядро

`mkga.core.kompas.connect()` возвращает объект с `api5`, `api7`, константами и `app7`. Подключение идёт к уже запущенному КОМПАСу; новый экземпляр запускается только по явному `launch=True`. Импорт `win32com` отложен, поэтому логика запускается и без pywin32 (фейковый КОМПАС), но CI и поддержка заявлены только для Windows. Для будущей Linux-версии КОМПАСа (API KsAPI) подключение нужно вынести за интерфейс, это в плане.
