# Запуск MKGA из меню КОМПАС

Хаб и моды можно открывать прямо из КОМПАС: пункты появляются в меню «Приложения → Утилиты» (рядом с «Калькулятором»).

## Как это устроено

КОМПАС хранит подключённые приложения и утилиты в файле `%APPDATA%\ASCON\KOMPAS-3D\<версия>\KOMPAS.kit.config`
(UTF-16 XML). Утилита это строка вида

```xml
<Utility path="C:\...\MKGA.exe" displayName="MKGA: хаб модов" params="" description="... [mkga]"/>
```

Так КОМПАС сам подключает «Калькулятор» и редактор библиотек; это штатный механизм «Конфигуратора» (Приложения →
Конфигуратор → Структура → Утилита: имя, путь, параметры, описание). MKGA вносит такие же записи без ручных кликов.
Никакой код в КОМПАС не внедряется: пункт просто запускает `MKGA.exe` (хаб) или `MKGA.exe run <мод>` отдельным процессом.

## Как включить

Из хаба: кнопка «Пункты в меню КОМПАС…» слева внизу. Или из командной строки:

```powershell
python -m mkga kompas-menu status                 # сколько пунктов MKGA сейчас в меню
python -m mkga kompas-menu add --dry-run          # показать, что изменится, ничего не записывая
python -m mkga kompas-menu add --exe путь\к\MKGA.exe   # добавить (хаб и все установленные моды-приложения)
python -m mkga kompas-menu remove                 # убрать пункты MKGA
```

Для собранной версии `--exe` не нужен (берётся сам `MKGA.exe`). После установки нового мода повторите `add`: набор
пунктов обновляется (старые пункты MKGA заменяются, а не дублируются).

## Установка модов для пунктов меню

Пункт «MKGA: <мод>» запускает `MKGA.exe`, а он ищет моды в настоящей папке `%APPDATA%\MKGA\mods`. Python из Microsoft Store подменяет новые файлы в `%APPDATA%` скрытой копией, поэтому мод, установленный через `python -m mkga install-zip`, `MKGA.exe` не увидит. Устанавливайте моды самим `mkga-cli.exe` (или кнопкой «Из файла» в хабе).

## Правила безопасности

- КОМПАС должен быть **закрыт**: иначе он перезапишет файл при выходе. Команда отказывается работать при запущенном КОМПАС
  (кроме `--dry-run`).
- Запись идёт через сессию отката: снимок файла, откат `python -m mkga undo <id>` (или страница «История изменений» в хабе).
- Меняются только строки с меткой `[mkga]` в описании. Чужие утилиты, приложения и библиотеки не затрагиваются.
- Перед записью результат проверяется как XML; формат, отличный от проверенного (не UTF-16, нет ни одной утилиты), даёт отказ.
- Файл другой версии КОМПАС меняется только по явному `--kompas-version` (по умолчанию все найденные).

## Что проверено

- Правка текста и файлов на синтетических и на КОПИИ настоящего файла КОМПАС v24: добавление, замена, удаление возвращает
  исходные байты, откат тоже (`tests/test_kompas_menu.py`).
- Кнопка хаба: добавление, удаление, отказ при запущенном КОМПАС.
- На живом КОМПАС v24 (25.11.2026): пункты появились в «Приложения → Утилиты», хаб и каталог комплектующих открываются из меню.

## Не проверено

- Другие версии КОМПАС (v25 и новее): формат файла может отличаться, тогда команда откажется менять файл.
- Размещение пункта на панели инструментов или горячая клавиша: это делается самим КОМПАС («Настройка интерфейса»), пункт
  меню для этого уже есть.
