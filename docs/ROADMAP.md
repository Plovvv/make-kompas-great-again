# Маршрут

Правила проекта: [PRINCIPLES.md](PRINCIPLES.md). Статусы: ✅ сделано, 🔄 в работе, ⬜ не начато.

## 0. Проверка ядра на живом КОМПАСе 🔄

- ✅ GUID библиотек типов API5, API7 и констант присутствуют в реестре v24 (24.11.2026).
- ✅ `hello-kompas` без блокирующего окна КОМПАСа: вывод в журнал.
- ✅ Подключение к открытому КОМПАСу v24 (только чтение), 25.11.2026: `connect()` присоединяется
  через `GetActiveObject` для `Kompas.Application.5` и `.7`, читает версию `(24, 0, 3, 0)`, число
  процессов КОМПАС не меняется. Если КОМПАС не запущен, `connect()` даёт понятную ошибку и НЕ
  запускает новый экземпляр (запуск только по `launch=True`). Закрытый КОМПАС в таблице
  запущенных объектов, естественно, не виден.
- ✅ `python -m mkga run-dev mods/_template` на открытом КОМПАСе: без документа «Нет открытого
  документа», с открытым документом печатает его имя; код выхода 0, процесс КОМПАС остаётся один.
- ✅ API5 на живом КОМПАСе v24: чтение свойств `ksIsStudyVersion`, `ksIsHomeVersion`,
  `ksIsSpdsVersion` (на полной версии все `False`), позднее связывание работает. Вызовы API5 с
  выходными параметрами (`ksGetSystemVersion` и т.п.) при позднем связывании требуют отдельной
  проверки, когда понадобятся.
- ⬜ Отчёт о проверке на v24 (полная редакция), затем на v25 и на учебной.

## 1. Ядро ✅ (кроме показа журнала и предпросмотра в интерфейсе: это шаг 2)

- ✅ `core/safe_io`: сессии записи со снимками, атомарная запись, журнал, откат «всё или ничего»
  с защитой от чужих правок, авто-откат при ошибке мода, предпросмотр (`dry_run`), удаление в
  корзину Windows, чистка хранилища. Для модов: `ctx.session(...)`. Для пользователя:
  `python -m mkga history` и `python -m mkga undo <id> [--force]`. Проверено на Windows
  (корзина, откат через CLI). ⬜ Кнопка «Отменить» в окне хаба, показ предпросмотра в UI.
- ✅ Правило версий (`core/versions.py`): проверено на версии из манифеста → без вопросов;
  новее или «дырка» → предупреждение и подтверждение (`--yes` в CLI); старее → отказ; версия всегда
  в журнале. Таблица возможностей `FEATURES` и `Kompas.supports()` есть, таблица пока пуста
  (в неё попадают только подтверждённые факты). Проверено на живом v24.
- ✅ Фейковый КОМПАС (`core/fake.py`, `--fake-kompas`) для тестов, CI и разработки без КОМПАСа.
- ✅ Тест-страж (`mkga/guard.py`, `python -m mkga check <папка>`, шаг в CI): моды не пишут файлы и
  не сохраняют документы в обход `ctx.session`; для документов есть `Kompas.save_as(session, doc, path)`.
  Это защита от случайных ошибок, а не от злого умысла.
- ✅ Настройки мода (`ctx.settings`, JSON в папке данных, атомарная запись, повреждённый файл не
  роняет мод) и обработка ошибок COM (`KompasError`, `com_errors`, понятные тексты для частых кодов,
  ошибка мода не роняет хаб: код выхода 2 и причина).
- ✅ Свои константы и подключение без `gencache`: `mkga/core/constants.py` (182 константы из
  `Kompas6Constants` v24, отобраны группами «с запасом»: типы документов, спецификация, штамп,
  объекты и операции 3D, размеры), генератор `python tools/gen_constants.py [--check]`, тест сверки
  с установленным КОМПАСом. `connect()` использует позднее связывание: кэш `gen_py` не создаётся и
  не нужен. Определение редакции: `Kompas.is_study / is_home / is_spds` (✅ на полной v24,
  ⬜ на учебной). Новые константы добавляются в группы `tools/gen_constants.py`.
- ⬜ Общий журнал действий мода и «предпросмотр изменений» в интерфейсе (механика в `safe_io` есть).

## 2. Единый стиль модов и хаб ✅ (остались мелочи, см. ниже)

Подробности и обоснование: [UI_STYLE.md](UI_STYLE.md).

- ✅ Изучено: FreeCAD Addon Manager, сравнение tkinter-тем и Qt. Образцов окон для приложений на API
  КОМПАСа не нашлось; надстройки других CAD разобраны только поверхностно.
- ✅ Решение: tkinter + ttk со своей современной темой (скругления рисуются под DPI на чистом Python,
  без зависимостей); светлая и тёмная палитры. Первый вариант на `vista` признан слишком простым.
- ✅ Тема (`mkga/ui/theme.py`, `raster.py`): кнопки, поля, карточки, плашки статуса, флажки,
  прокрутка, прогресс, таблица, значки Segoe Fluent, цвет заголовка окна. Проверено на экране 200%.
- ✅ Каркас `ModWindow`: карточки «Параметры» и «Что будет сделано», тёмный журнал, плашка статуса
  КОМПАСа, действия в рабочем потоке с COM, подтверждение версии диалогом.
- ✅ Образец `python -m mkga ui-demo [--dark]`, тесты окна и растеризатора (147 тестов всего).
- ✅ Окно хаба (`mkga/ui/hub.py`) на общей основе окон (`ui/base.py`): боковая навигация,
  «Каталог» и «Установленные» с карточкой деталей (версия, автор, лицензия, совместимость с вашим
  КОМПАСом), установка и обновление одной кнопкой, установка из файла с предупреждением, удаление с
  подтверждением, «История изменений» с кнопкой «Отменить» (и вопросом, если файл менялся после
  операции), тема светлая/тёмная/как в Windows (сохраняется), понятные состояния «пусто» и «каталог
  недоступен». Моды запускаются ОТДЕЛЬНЫМ процессом (`mkga/launcher.py`): сбой мода хаб не роняет, вывод
  мода попадает в журнал хаба. Логика вынесена в `mkga/hub_model.py` и покрыта тестами.
- ✅ Адрес реестра по умолчанию задан (`mkga/config.py`: реестр в репозитории проекта).
- ⬜ Проверить окно с настоящим КОМПАСом в сценарии «подключён» (проверены «не запущен» и фейк).
- ⬜ Иконка приложения, ускорение первого кадра (около секунды), проверка хаба с подключённым КОМПАСом и реальной установкой мода из GitHub (пока в каталоге нет модов).
