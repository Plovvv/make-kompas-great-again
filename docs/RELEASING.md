# Как выпустить версию

Для мейнтейнера. Выпуск это публикация в репозитории: делается осознанно и после проверки по списку ниже.

## Что выпускается

| Что | Как называется | Откуда берётся |
|---|---|---|
| Хаб с модами в поставке | `MKGA-<версия>-windows.zip` (`MKGA.exe`, `mkga-cli.exe`, папка `bundled/` с модами) | `python tools/build_exe.py` |
| Контрольные суммы | `SHA256SUMS.txt` | `Get-FileHash` / `sha256sum` по файлам релиза |
| Архив мода (для реестра и ручной установки) | `<id>-v<версия мода>.zip` | `python -m mkga pack mods/<id> --repo owner/name` |

Версия хаба: `mkga/__init__.py` (`__version__`); версия мода: `mkga-mod.json`. Теги релизов хаба: `v<версия хаба>`.
Мод из поставки обновляется вместе с релизом хаба; в реестр на GitHub записи попадают, когда у мода есть собственный релиз
(для модов других авторов), см. [WRITING_MODS.md](WRITING_MODS.md).

## Список проверок перед выпуском

1. `python -m unittest discover -s tests -t .` без ошибок; `python tools/validate_registry.py`; `python -m mkga check mods`.
2. Живая проверка при запущенном КОМПАС: `MKGA_LIVE_KOMPAS=1 python -m unittest tests.test_live_kompas tests.test_live_model3d tests.test_live_components`.
3. Версия хаба и версии модов подняты, `CHANGELOG.md` дополнен, документация и `docs/ROADMAP.md` актуальны, в `README.md` нет
   устаревших утверждений.
4. `python tools/build_exe.py`: автопроверка в окружении без Python проходит, мод из поставки ставится без сети.
5. Ручная проверка собранной папки: распаковать zip в чистую папку, запустить `MKGA.exe`, установить «Каталог комплектующих»
   из каталога, создать деталь при запущенном КОМПАС, открыть хаб из меню КОМПАС.
6. Личных данных автора в файлах нет (имена, пути, адреса): `git grep` по своему имени и пути профиля.

## Публикация

Автоматически: отправьте тег, и workflow `.github/workflows/release.yml` соберёт exe на Windows-раннере, проверит и приложит
архив и контрольные суммы к релизу (черновик, который вы сами публикуете).

```powershell
git tag v0.1.0
git push origin v0.1.0
```

Вручную: соберите `python tools/build_exe.py`, создайте релиз на GitHub с тегом `v<версия>`, приложите
`build/MKGA-<версия>-windows.zip` и `SHA256SUMS.txt`.

После публикации скачайте архив со страницы релиза и пройдите пункт 5 списка ещё раз (на скачанном, а не на локальном файле).

## Реестр модов

Моды других авторов попадают в `registry/registry.json` через pull request (запись печатает `mkga pack --repo ...`, хеш
проверяет CI). Хеш в реестре должен совпадать с файлом в релизе: архив воспроизводим, поэтому его можно собрать заново и
сравнить. Поставляемые моды в реестр заносить не обязательно.
