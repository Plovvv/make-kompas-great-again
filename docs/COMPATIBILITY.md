версии и прислать отчёт: [VERIFICATION.md](VERIFICATION.md).

## Что известно про версии

- **v25:** хаб подключается к КОМПАС и читает версию 25.0.0.0 (полная). Пользовательский файл `KOMPAS.kit.config` v25 по умолчанию пуст (`<Groups/>`), в отличие от v24, где в нём уже есть утилиты: пункты меню MKGA для него добавляются созданием группы (не проверено в самом КОМПАС v25, откат есть). Остальное на v25 не проверялось.

- Библиотеки типов API5, API7 и констант регистрируются установкой КОМПАС; на v24 их GUID подтверждены в реестре.
- Редакцию определяют свойства API5 `ksIsStudyVersion`, `ksIsHomeVersion`, `ksIsSpdsVersion` (на полной v24 все `False`).
- Значения констант и поведение API могут отличаться между версиями. Живой тест `tests/test_live_kompas.py` сверяет
  константы с установленной библиотекой, а `tests/test_live_model3d.py` сверяет построенные тела с расчётом.

## Правила для модов

Мод в манифесте (`kompas_versions`) перечисляет только версии, на которых он реально запускался. Для версии вне списка хаб
показывает предупреждение и просит подтверждение; для версии старше проверенных запуск отменяется (`docs/PRINCIPLES.md`,
раздел «Версии КОМПАС»).
