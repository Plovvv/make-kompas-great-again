# История версий

Неофициальный проект, с АСКОН не связан. «Проверено» значит проверено на КОМПАС-3D v24 (полная версия); остальное не проверялось.

## 0.1.0 (подготовлена к выпуску)

Хаб (`MKGA.exe`) и мод «Каталог комплектующих» 0.5.0 в поставке.

**Хаб и ядро**
- Каталог модов, установка и обновление с проверкой хеша, установка из файла, запуск мода отдельным процессом, история
  изменений файлов с откатом (удаление только в корзину), светлая и тёмная тема.
- Моды в поставке: «Каталог комплектующих» ставится кнопкой без интернета и без реестра.
- Пункты в меню КОМПАС («Приложения → Утилиты») для хаба и модов: запись в `KOMPAS.kit.config` при закрытом КОМПАС, с откатом.
- Ядро: подключение к запущенному КОМПАС (API5 и API7), безопасная запись с откатом, правило версий КОМПАС
  (проверено / предупреждение / отказ), фейковый КОМПАС для тестов, построение 3D-деталей с проверкой объёма по формуле.
- Сборка exe без Python на машине пользователя (PyInstaller, onedir).

**Мод «Каталог комплектующих» 0.5.0** — 40 типов: винты и болты DIN/ISO (912, 7984, 6912, 7991, 7380-1/-2, 933, 931, 960, 961, 84, 963,
965, 7985, 913, 914, 916), гайки (934, 439, 985, 986, 1587, 557), шайбы (125 A/B, 433, 9021, 127, 7980, 6797), штифты
(ISO 2338, ISO 8734), стопорные кольца (471, 472) и покупные изделия без стандарта (вплавляемые вставки, шестигранные
стойки, Т-гайка, пневматические фитинги push-in). Имя файла и «Наименование» по вашей схеме (их можно править, в том числе
насовсем для стандарта), раздел спецификации ставится сам, резьба условным изображением, чертёж с размерами, свои детали
таблицей (в том числе с помощью ИИ).

**Исправлено после первых проверок на другом компьютере (КОМПАС v25)**
- Кнопки «Установить / Запустить / Удалить» в карточке мода стоят сверху и не обрезаются на маленьком экране.
- Пункты в меню КОМПАС добавляются и в пустой пользовательский файл настроек v25 (раньше хаб отказывал).

**Ограничения**
- Проверено только на КОМПАС-3D v24 (полная версия). Другие версии и учебная редакция не проверялись.
- Размеры из открытых каталогов не сверены с оригиналами стандартов; для вставок, фитингов и Т-гаек они типовые. Модели
  упрощены (резьба условная, шлицы и зубья упрощены), см. README мода.
- exe не подписан: Windows SmartScreen может показать предупреждение.
- Реестр модов на GitHub пока пуст (мод идёт в поставке).
