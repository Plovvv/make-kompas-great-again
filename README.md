# MAKE KOMPAS GREAT AGAIN

Открытый набор модов и надстроек для КОМПАС-3D и хаб, который их находит, ставит и запускает.

> **Неофициальный проект.** Он не связан с компанией АСКОН и не одобрен ею. «КОМПАС» и «КОМПАС-3D» — товарные знаки АСКОН. Для работы нужен установленный у вас КОМПАС-3D с собственной лицензией. Проект не распространяет программное обеспечение, базы данных и модели АСКОН.

## Что это

В КОМПАСе есть мощное API, но нет привычного для FreeCAD, Obsidian или VS Code способа делиться дополнениями: найти мод, поставить его одной кнопкой, обновить. MKGA закрывает эту дыру:

- **Хаб**: каталог модов из реестра на GitHub, установка и обновление с проверкой хеша, запуск, **история изменений с кнопкой «Отменить»**, светлая и тёмная тема.
- **Ядро** (`mkga.core`): подключение к запущенному КОМПАСу, безопасная запись файлов с откатом, построение 3D-деталей с автоматической сверкой объёма.
- **Моды**: отдельные небольшие приложения и макросы, каждый запускается отдельным процессом. Сбой одного мода не роняет хаб и другие моды.

## Принципы

1. **«Не убий»:** мод не должен повредить файлы пользователя и КОМПАС. Файлы меняются только с откатом и предпросмотром, удаление только в корзину.
2. **Стабильность:** работает на любом компьютере без установки Python и пакетов (собранный exe), не зависит от сети во время работы.
3. **Открытость:** понятный интерфейс, понятный код, данные только из первоисточников.
4. **Проверяемость:** результат построения сверяется с расчётом, непроверенное честно помечено.

Подробно: [docs/PRINCIPLES.md](docs/PRINCIPLES.md).

## Статус

Версия 0.1 (мод «Каталог комплектующих» 0.5). Ядро, 3D-слой, хаб, выпуск и проверка модов готовы; всё проверено на **КОМПАС-3D v24 (полная версия)**. Первый мод готов: **[Каталог комплектующих](mods/components/README.md)** (40 типов: винты, болты, гайки, шайбы, штифты, стопорные кольца DIN/ISO, вставки, стойки, Т-гайки и пневматические фитинги: деталь с нужным именем и разделом спецификации, чертёж с размерами, свои детали таблицей). Он входит в поставку хаба; реестр модов на GitHub пока пуст. Другие версии и редакции КОМПАС не проверялись, отчёты о проверке очень нужны ([docs/VERIFICATION.md](docs/VERIFICATION.md), матрица: [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)). План и статусы: [docs/ROADMAP.md](docs/ROADMAP.md).

## Установка

**Для пользователей (Windows, Python не нужен).** Скачайте `MKGA-<версия>-windows.zip` со страницы
[Releases](https://github.com/Plovvv/make-kompas-great-again/releases), распакуйте, запустите `MKGA.exe`, в «Каталоге» поставьте
«Каталог комплектующих» (он входит в архив, интернет не нужен). Хаб и моды можно открывать прямо из меню КОМПАС
(«Приложения → Утилиты»). Пошагово и с решением типичных проблем: **[docs/INSTALL.md](docs/INSTALL.md)**. exe пока не подписан:
Windows SmartScreen может показать предупреждение. КОМПАС-3D должен быть установлен и запущен, когда вы запускаете моды.
Моды и их данные хранятся в `%APPDATA%\MKGA`. История версий: [CHANGELOG.md](CHANGELOG.md).

**Собрать самому.** `python tools/build_exe.py` (подробности: [docs/DISTRIBUTION.md](docs/DISTRIBUTION.md)); выпуск версии:
[docs/RELEASING.md](docs/RELEASING.md).

**Из исходников.** Нужны Windows, Python 3.10+ и `pywin32` (для связи с КОМПАСом):

```
pip install pywin32
python -m mkga gui
```

## Для разработчиков

```
python -m unittest discover -s tests -t .       # тесты без КОМПАС (живые пропускаются)
python -m mkga check mods                       # страж: нет записи файлов в обход ctx.session
python -m mkga run-dev mods/_template --fake-kompas
python -m mkga run-dev mods/components           # мод «Каталог комплектующих» (нужен запущенный КОМПАС)
python -m mkga ui-demo --fake-kompas            # образец окна мода
python tools/inspect_api.py find Extrusion      # справочник по API КОМПАС из библиотеки типов
```

С открытым КОМПАС можно прогнать живые проверки (создают свой документ, ваши не трогают):
`MKGA_LIVE_KOMPAS=1 python -m unittest tests.test_live_kompas tests.test_live_model3d tests.test_live_components -v`.
