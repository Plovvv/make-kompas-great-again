# MAKE KOMPAS GREAT AGAIN

Открытый набор модов и надстроек для КОМПАС-3D и маленький хаб, который их находит, ставит и запускает.

> **Неофициальный проект.** Он не связан с компанией АСКОН и не одобрен ею. «КОМПАС» и «КОМПАС-3D» — товарные знаки АСКОН. Для работы нужен установленный у вас КОМПАС-3D с собственной лицензией. Проект не распространяет программное обеспечение, базы данных и модели АСКОН.

## Что это

В КОМПАСе есть мощное API, но нет привычного для FreeCAD, Obsidian или VS Code способа делиться дополнениями: найти мод, поставить его одной кнопкой, обновить. MKGA закрывает эту дыру:

- **Хаб** (`python -m mkga gui`): каталог модов из реестра на GitHub, установка с проверкой хеша, запуск.
- **Ядро** (`mkga.core`): подключение к запущенному КОМПАСу через COM (API5 + API7).
- **Моды** (`mods/`): отдельные небольшие приложения и макросы. Каждый мод описывается манифестом `mkga-mod.json`.

## Статус

Версия 0.1, каркас. Хаб, реестр, установщик и запуск написаны и покрыты тестами, которые идут без КОМПАСа. Подключение к КОМПАСу (`mkga/core/kompas.py`) и окно хаба пока не проверены на реальной машине, это первый пункт плана.

## Быстрый старт (разработка)

Нужен Python 3.10+.

```
python -m unittest discover -s tests -t .
python -m mkga validate mods/_template
python -m mkga install-zip путь\к\моду.zip
python -m mkga list
python -m mkga run hello-kompas      # нужен Windows, КОМПАС и pywin32
python -m mkga gui
```

## План

1. Проверить `core/kompas.py` и окно хаба на КОМПАСе v24, исправить GUID и подключение.
2. Сделать первый настоящий мод: **«Метизы и фитинги»** (`mods/fasteners`), сначала каталог и поиск, затем построение деталей. План и границы в `mods/fasteners/README.md`.
3. Вынести в моды уже готовые инструменты: перевод файлов в старые версии КОМПАСа («КОМПАС → v22»), свой «Комплектовщик», оформление ЕСКД (обозначения, разделы спецификации, материалы).
4. Релизы: сборка zip-архивов модов и exe хаба на GitHub Actions, публикация записей в `registry/registry.json`.
5. Версии КОМПАСа и Linux: матрица проверенных версий, слой совместимости под KsAPI.
